# Electrical Calculations ⚡
ماشین حساب مهندسی برق (اندروید): الکتروتکنیک، برق قدرت، الکترونیک، ابزار دقیق.

## ساخت APK
1. ریپازیتوری جدید در GitHub بسازید و همه فایل‌ها را push کنید.
2. تب **Actions** → *Build APK* (خودکار اجرا می‌شود).
3. از بخش Artifacts فایل `app-debug.apk` را دانلود و نصب کنید.

افزودن فرمول: در `app/src/main/assets/index.html` آرایه `C` را ویرایش کنید.
